9  Comparison of the single substances experiment with the mixture experiment ?

  • Show All Code
  • Hide All Code
  • View Source

Because the single substances were tested again during the mixture experiment, the goal here is to compare the observed effects in both experiments and therefore to judge the reproducibility between the experiments. We then need to compare the dose-response curves for EPX & IMD obtained with the experiment UNI and the experiment MIX (Autumn 2024 vs. Spring 2025).

9.4 Dose-response curves

We then get the dose-response curves of the single substances from experiment UNI and experiment MIX.

9.4.1 Experiment UNI - Dose-response curves

Code 
drc.ExpA <- drm(
  Nb_cocoons ~ Dose, Molecule,
  data = df_expA_repro,
  type = "Poisson",
  fct = LL.4(
    names = c("slope", "Ymin", "Ymax", "EC50"),
    fixed = c(NA, 0, NA, NA)
  ),
  # Reproduction is expected to reach 0 for large concentrations
  pmodels = data.frame(Molecule, Molecule, Molecule)
)

data_CI_ExpA <- f_CI_drc(
  Dose_min = Val_Ctrl,
  Dose_max = 5000,
  Molecules = c("EPX", "IMD"),

)
